# Versioning

This project uses semantic versioning:

- **MAJOR**: incompatible changes to framework structure or report schema
- **MINOR**: new capabilities (new checks, new modules, new flow phases)
- **PATCH**: fixes and small improvements

## Safety Note

Versions prior to 1.0.0 are considered evolving and are intended for lab validation.
Upgrade execution actions are intentionally excluded from early versions to prevent unsafe production usage.
