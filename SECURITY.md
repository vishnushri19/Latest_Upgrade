# Security Policy

## Supported Versions

This project is intended for lab validation and architectural reference.
It does not execute upgrade or failover actions in early versions.

## Reporting a Vulnerability

If you discover a security issue (for example: unsafe handling of credentials, accidental logging of secrets, or risky automation behavior), please do not open a public issue.

Instead:
- Open a private disclosure by contacting the repository owner directly (via GitHub profile contact options).

## Sensitive Data Rules

Do not share:
- Customer names
- Hostnames, IPs, certificates, or internal URLs
- Configuration snippets from production environments
- Any credential material or secrets

All examples should be sanitized and lab-only.
